# Discord Bot

A simple Discord Bot built with JavaScript and Discord.js.

## Features

- !help
- !rules
- !contact
- !github
- !about

## Technologies

- JavaScript
- Node.js
- Discord.js v13
- dotenv

## Installation

```bash
npm install
```

## Run

```bash
node bot.js
```

## Environment Variables

Create a `.env` file:

```env
TOKEN=YOUR_DISCORD_BOT_TOKEN
```
